# CH · 缠论三类买卖点（v1）

> 触发标签：`CH-v1`　｜　适用：全环境（尤其震荡转趋势）　｜　状态：待启用（0 笔）

## 一、为什么选缠论而不是全盘照搬

缠论最有价值的部分是**中枢**和**三类买卖点**——前者给出"当前是震荡还是离开"的客观定义，后者给出"离开之后第一次回踩不回到中枢"的入场点。

其余部分（笔的严格划分、线段、走势类型）主观性太强，本策略只取可客观化的部分。

## 二、可操作的最小定义

| 概念 | 本策略的判定标准 |
|---|---|
| **分型** | 连续 3 根 K 线：中间那根的 high 最高 = 顶分型；low 最低 = 底分型 |
| **笔** | 顶分型与底分型之间至少 **5 根 K 线**（含端点），且两分型不重叠 |
| **中枢** | 连续 **3 笔以上**价格区间有重叠，中枢区间 = [max(低点), min(高点)] |
| **离开** | 价格收盘在上（下）方，且该笔幅度 > 中枢高度的 **1.5 倍** |

## 三、三类买卖点（本策略只做第三类）

| 类型 | 定义 | 是否做 |
|---|---|---|
| 一买 | 下跌趋势末端，背驰后反转 | ❌ 逆势，胜率低 |
| 二买 | 一买后的第一次回踩不破前低 | ❌ 一买本身难判定 |
| **三买** | **离开中枢向上后，回踩不回到中枢上沿** | ✅ **只做这个** |

**三买的可操作定义**：
1. 价格曾在中枢内震荡（≥3 笔）
2. 向上离开中枢，收盘在中枢上方，幅度 > 1.5× 中枢高度
3. 回踩的最低点 **> 中枢上沿**（不回到中枢内）
4. 回踩结束时买入

## 四、入场、止损、目标

| | 三买（做多） |
|---|---|
| 入场 | 回踩结束的 15m 反转确认（收盘站上回踩段高点） |
| 止损 | **中枢上沿下方 0.1%**（这是策略的核心：中枢上沿就是多空分界） |
| 目标 | 下一中枢形成前的 2–3R；或前高 |
| 失效 | 价格收盘回到中枢内 |

止损位置由结构直接给出，不需要猜——这是缠论相比其它主观方法的最大优势。

## 五、与 TB 的区别

| | TB（突破回踩） | CH（三买） |
|---|---|---|
| 突破对象 | 价格区间上沿 | 中枢上沿（震荡结构的边界） |
| 止损依据 | 回踩低点 | 中枢上沿 |
| 适用 | 明确趋势 | 震荡转趋势 |
| 重叠度 | 高——**同一笔交易不要重复计入两个策略**，按先触发者归类 |

## 六、主观性风险与对策

| 风险 | 对策 |
|---|---|
| 笔的划分因人而异 | 用 5 根 K 线硬性规则，不满足就不是笔 |
| 中枢包含关系处理 | 只取"3 笔重叠区间"，不做复杂的包含合并 |
| 事后重画 | 中枢上下沿在入场时写死，事后不得修改 |

## 七、启用条件

先用纸面历史数据**完整标注 20 个中枢 + 三买点**，标注结果能重复（隔天重新标一遍，结论一致）才启用。当前 0 笔。
