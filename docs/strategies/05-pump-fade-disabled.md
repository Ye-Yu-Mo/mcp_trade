# PF · 拉盘退潮做空（禁用，仅观察）

> 触发标签：`PF-v1`　｜　适用：事件驱动　｜　状态：**禁用**

## 一、为什么记录它

2026-10-27 用户手动做过同类交易并盈利（DOOD +3.21U），因此有必要把它的**真实边界**写清楚：不是不能做，是**我们的账户规模做不了**。

## 二、机会描述

新币/低流通币被拉盘后（24h +100% 以上），价格进入派发阶段，出现：
- 资金费率飙高（多头拥挤）
- OI 快速上升而价格滞涨
- 15m 出现长上影 + 放量

理论上做空有高赔率。

## 三、禁用原因（数学，不是偏好）

**用 34U 账户、1.5% 风险试算：**

```
风险金额 = 34 × 1.5% = 0.51U
止损距离 = 10%（这类币的正常波动）
可开数量 = 0.51 / 0.10 = 名义 5.1U
```

而这类币的**交易所最小名义价值通常是 5 USDT**——刚好卡在线上，且实际要留出滑点余量，往往直接下不去单。

即使下得去，10% 的止损距离意味着：**一次插针就能打穿**，止损成交价可能比设定差 3–5%，实际亏损变成 -1.5R。

## 四、什么情况下可以重新考虑

| 条件 | 说明 |
|---|---|
| 账户 ≥ 200U | 名义限制不再卡死 |
| 该币有 ≥7 天连续交易历史 | 排除新币插针 |
| 有盘口深度数据 | 能评估滑点 |

三条全满足前，这个策略保持禁用。

## 五、观察价值

即使不做，这些币的**资金费率和 OI 异常**是很好的市场温度计：
- 多个小币同时出现极端正费率 → 市场情绪过热，主流币可能要回调
- 拉盘币集体崩塌 → 风险偏好下降，适合减少多头暴露
