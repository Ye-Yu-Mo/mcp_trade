# SMC · 聪明钱概念 / ICT（v1）

> 触发标签：`SMC-v1`　｜　适用：全环境　｜　状态：待启用（0 笔）

## 一、核心思想

市场在**流动性**之间移动：价格倾向于先扫掉一侧的止损（liquidity sweep），再向真正的目标（订单块 / 失衡区）运行。

三个概念，本策略只用可量化的部分：

| 概念 | 定义（可量化） |
|---|---|
| **流动性扫荡** | 价格突破前高/前低 0.1% 以内，随后 3 根内收回 |
| **公平价值缺口 FVG** | 连续 3 根 K 线：第 1 根高点 < 第 3 根低点（看涨缺口），反之看跌 |
| **订单块 OB** | 扫荡前的最后一根反向 K 线（做多时是最后一根阴线） |

## 二、交易模型：扫荡 → 回踩 FVG → 入场

```
1. 前低被扫（跌破后 3 根内收回）        ← 流动性已收割
2. 价格向上留下一个 FVG                ← 失衡
3. 回踩到 FVG 上沿（做多）             ← 入场点
4. 止损放在扫荡低点下方                ← 结构止损
```

**不做**纯 FVG 交易（没有扫荡的缺口太多，胜率低）。

## 三、与 RF / WY 的关系

| | RF（区间假突破） | WY（Spring） | SMC（扫荡回踩） |
|---|---|---|---|
| 触发 | 区间上沿假突破 | 区间下沿假跌破 + 量 | 任意前低扫荡 + FVG |
| 入场 | 立刻反向 | 收回后 | **等回踩 FVG** |
| 止损 | 插针高点 | 弹簧低点 | 扫荡低点 |

三者捕捉的是同一现象的三种表达。**同一笔交易只归一个策略**，按先触发的规则归类，避免重复计入统计。

## 四、数据支持

- 扫荡判定：K 线高低点（已有）
- FVG 判定：K 线高低点（已有）
- **加分项**：扫荡期间是否出现强平（`market.liquidations`），有强平的扫荡质量更高

## 五、止损与目标

| | 做多 |
|---|---|
| 止损 | 扫荡最低点下方 0.1% |
| 目标 1 | 扫荡前的高点（1–2R） |
| 目标 2 | 上一个订单块 / 日高 |

## 六、主观性风险

- "哪个前低值得扫"有选择性偏差 → 只认 **24h 低点**和**最近 3 个 1h 摆动低点**
- FVG 数量多 → 只认扫荡后的第一个 FVG

## 七、启用条件

标注 20 个历史扫荡案例（含是否伴随强平），确认可复现后启用。
