# TB · 趋势突破回踩（v1）

> 触发标签：`TB-v1`　｜　适用：趋势市　｜　状态：验证中（3 笔：1 胜 2 负）

## 一、这个策略在赌什么

**赌"点火之后的第一次回踩会被接住"。** 不是赌突破本身，是赌突破后的第一次回撤有人接。

如果没人接（回踩直接跌回点火区），说明突破是假的，立刻走。

## 二、识别条件（全部满足才算点火）

| 条件 | 数值 | 说明 |
|---|---|---|
| 突破 | 价格突破前 N 根（N≥20）的区间上沿 | 不是"接近"，是收盘站上去 |
| 量能 | 突破 K 线成交量 ≥ 前 20 根均量的 **2 倍** | 低于 2 倍不算点火 |
| 买盘 | 突破 K 线主动买占比 ≥ **55%** | 用 taker buy / volume 算 |
| 时段 | ASIA_AM（08–10 北京）或 US_OPEN（21:30–22:30） | 低流动性时段的突破不参与 |

四条缺一，不进入观察名单。

## 三、入场

两个子模式，按当时情况二选一，**不能都做**：

### TB-A 回踩挂单（优先）
- 回踩到突破位上方 0–0.3% 区间
- **挂限价单**（maker，省手续费）
- 必须带 `expire_minutes`（默认 90）
- 风险最低，但可能不成交

### TB-B 确认入场（回踩已结束）
- 15m 收盘重新站上回踩段高点
- 且该根买占比 > 50%
- **入场价距突破位必须 < 0.3%**，超过就放弃（等下一次回踩）
- 市价入场

> **为什么加 0.3% 限制**：HYPE 那笔在突破高点附近追进，止损距离 0.68%，一个正常回抽就扫掉了。-0.4U 换来的规则。

## 四、止损

**放在回踩低点下方 0.05–0.1%**，或点火 K 线低点下方，取更近的那个。

不允许"用固定百分比"当止损——止损必须对应结构。

## 五、目标与出场

| 触发 | 动作 |
|---|---|
| **+3R** | 平一半，剩余止损移保本 |
| **+1R 且 15m 出现更高低点** | 止损移保本 |
| **1h 收盘跌回突破位下方** | 全部平仓（不等止损） |
| **入场后 8 根 1h 未到 +1R** | 时间止损 |
| **跌回点火起点** | 立刻平 |

> 目标从 2.5R 提到 3R：小账户手续费占风险 15%，2.5R 的净收益不够覆盖摩擦。

## 六、失效条件（出现任一，形态作废）

1. 价格跌回点火 K 线起点（不是止损位，是起点）
2. 回踩量能大于点火量能的 70%（说明是出货不是回踩）
3. 突破后 3 根 15m 买占比连续下滑且都 < 45%（ETH 那笔的形态）

## 七、已知失败模式

| 模式 | 案例 | 症状 |
|---|---|---|
| 追确认买在最高点 | HYPE -1.22R | 等确认等到价格已经跑掉，R:R 被压缩 |
| 低流动性时段点火 | ETH -0.50R | 亚洲深夜突破，没有接力盘 |
| 回撤"看起来有承接"就提前进 | MUU -1.06R | 挂限价在回踩位，价格还没证明 |

## 八、仓位计算

```
数量 = 风险金额 / |入场价 - 止损价|
再受 1.5x 权益名义上限约束取小值
```

名义上限经常先触发（小账户 + 紧止损），此时实际风险会低于 1%，属于正常。

- 淘汰线：期望值 < 0 且样本 ≥ 20
