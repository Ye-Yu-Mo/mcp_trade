# RF · 区间假突破反转（YTC v1）

> 触发标签：`RF-v1`　｜　适用：震荡市　｜　状态：验证中（1 笔：+3.06R）

## 一、这个策略在赌什么

**赌区间边缘的突破是假的。** 价格冲到区间上沿之外、扫掉止损、然后回到区间内——这时做反向，赌它走回区间另一头。

本质是**利用别人的止损**：区间边缘的突破单和止损单是堆在一起的，扫完就没有后续买盘了。

## 二、识别条件

| 条件 | 数值 |
|---|---|
| 区间 | 价格在 24h 内至少 2 次触及同一上沿（容差 0.2%） |
| 假突破 | 价格突破上沿后，**15m 收盘回到上沿之内** |
| 拒绝影线 | 突破那根 K 线的上影线 ≥ 实体的 50%（说明冲上去被砸回来） |
| 时段 | 不限（区间边缘全天有效） |

## 三、入场

- **挂限价单**回到区间内 0.1–0.3% 处（maker）
- 或 15m 收盘确认回到区间内后市价入场
- `expire_minutes` 120

## 四、止损与目标

| | 做空（上沿假突破） |
|---|---|
| 止损 | 假突破那根 K 线最高点上方 0.1% |
| 目标 | 区间中位（1R）→ 区间下沿（2.5–3R） |
| 移动止损 | +1R 且 15m 出现更低高点 → 移保本 |

**对称适用于下沿假突破做多。**

## 五、失效条件

1. 价格再次收盘突破上沿（第二次突破通常是真的）
2. 突破 K 线量能持续放大（说明是真买盘）
3. 区间宽度 < 2×ATR（太窄，R:R 不够）

## 六、已验证案例

**SOL 2026-10-26：+3.06R**
- 24h 区间上沿 102.7，价格冲到 102.71 后 15m 收回
- 入场 102.10，止损 102.80，目标 99.90
- +1R 后移保本，最终 99.89 触达止盈

## 七、已知风险

- **第二次突破往往是真的**——同一个位置被测试 3 次以上时，假突破概率下降，真突破概率上升
- 区间识别有主观性，需要用 24h 高低点作为锚，不靠"看起来像个区间"

## 八、样本要求

与 TB 相同：20 笔后评估，期望 > +0.2R、PF > 1.3。
