# 策略库

每个策略都必须满足三个条件才算存在：**可追溯**（每笔交易能归到某个策略版本）、**可操作**（任何人读完能独立执行同一套动作）、**可证伪**（有明确的失效条件和淘汰标准）。

## 通用规则（所有策略共享，不允许单笔例外）

| 项目 | 规则 |
|---|---|
| 单笔风险 | 纸面 1%，实盘 1.5%（服务端强制） |
| 止损 | 开仓必须带，且方向正确；不设止损的单不存在 |
| 同时持仓 | 纸面最多 2 笔，实盘 1 笔 |
| 总风险 | ≤ 3% 权益 |
| 名义价值 | ≤ 1.5x 权益（小账户下这是真正约束条件） |
| 加仓 | 只加盈利仓，且加仓后总风险 ≤1.5%；**永不摊平亏损仓** |
| 日亏损 | -3% 停当天 |
| 连亏 | 3 笔停手复盘 |
| 时段 | 突破类只在美股开盘后 1h 或亚洲早段 8–10 点执行 |
| 标的 | 24h 暴涨 >200% 的新币永久排除 |

## 手续费与入场方式

| 方式 | 费率 | 适用 |
|---|---|---|
| **挂单（maker）入场** | 0.02% | 默认。价格已到预设位、不需要抢的时候 |
| 市价（taker）入场 | 0.05% | 只在确认触发后必须立刻进时用 |
| 出场 | 一律 taker | 止损/止盈不允许挂单等成交 |

**入场优先挂单**：省 0.015U/单边 + 免滑点。代价是可能不成交，所以每张挂单必须带 `expire_minutes`。

## 每笔交易必须记录的字段

这些字段决定策略能否被评估，缺一项该笔不计入统计：

```
strategy_id   策略 ID + 版本（如 TB-v1）
symbol        标的
session       时段（ASIA_AM / US_OPEN / US_MAIN / OFF_HOURS）
trigger       触发条件的具体数值（如 close>81.85, buy%=53.6）
context       当时的 OI 变化、ATR、24h 涨跌幅
entry / stop / tp
risk_amount   风险金额
fill_type     maker / taker
r_multiple    最终 R
exit_reason   STOP / TP / STRUCTURE_BREAK / TIME_STOP / MANUAL
```

## 评估标准（每个策略独立计算，不能混在一起看）

| 指标 | 通过线 | 淘汰线 |
|---|---|---|
| 样本数 | ≥ 20 笔才评估 | — |
| 期望值 | > +0.2R | < 0 且样本 ≥ 20 → 淘汰 |
| Profit Factor | > 1.3 | < 1.0 |
| 最大回撤 | < 10R | > 15R |
| 复现性 | 任意两笔同 setup 的执行动作一致 | 需要"看情况"的 → 规则不合格，回炉 |

**淘汰是正常结果。** 一个策略被证伪，比五个策略都"感觉还行"更有价值。

## 版本管理

- 规则改动 = 版本号 +1（TB-v1 → TB-v2），旧样本保留但标记版本
- 不允许在亏损后临时改规则再继续用同一版本，那会污染统计
- 改动的理由写进 `docs/strategies/CHANGELOG.md`

## 候选理论（已评估，暂不建文档）

| 理论 | 为什么不建 |
|---|---|
| **斐波那契回撤/扩展** | 不能独立成策略——单独用它等于"猜支撑"。作为 `TB`/`RF` 的**辅助过滤**（回撤位与结构位重合时加分），不单独计样本 |
| **资金费率极值反转** | 有潜力，但当前只有实时费率，缺历史序列。需要先补 `/fapi/v1/fundingRate` 接口再评估 |
| **均值回归（统计套利）** | 需要 z-score、协整等统计工具，且更适合多标的配对。当前单标的账户做不了 |
| **江恩理论（角度线/时间窗）** | **排除**。规则无法客观化——同一张图可以画出多个"有效"角度线，无法证伪，不符合本库的准入标准 |
| **蜡烛形态（Pin bar / 吞没 / 十字星）** | 太微观，单独胜率接近抛硬币。只在 `WY` 的 No Supply 判定里作为辅助条件使用 |
| **周期分析（时间之窗）** | 与江恩同类问题：事后总能找到"吻合"的周期，无法事前验证 |

## 策略之间的重叠处理

`RF`、`WY`、`SMC` 三者捕捉的是同一现象（扫止损后反转）的三种表达；`TB` 与 `CH` 的第三类买点高度重叠。

**规则：同一笔交易只归入先触发条件的那个策略，不允许重复计入两个策略的统计。** 否则样本量会虚高，评估失真。
