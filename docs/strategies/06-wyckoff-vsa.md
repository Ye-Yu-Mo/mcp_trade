# WY · 威科夫 / 量价分析（VSA v1）

> 触发标签：`WY-v1`　｜　适用：全环境（尤其横盘后）　｜　状态：待启用（0 笔）

## 一、核心思想

价格是结果，**成交量和波动幅度（spread）**才是原因。威科夫把市场分成四个阶段：

| 阶段 | 特征 | 我们做什么 |
|---|---|---|
| **吸筹**（Accumulation） | 横盘、缩量、下跌被快速买回 | 观察，不交易 |
| **拉升**（Markup） | 放量突破吸筹区 | **Spring 后入场** |
| **派发**（Distribution） | 高位横盘、放量不涨 | 观察 |
| **下跌**（Markdown） | 放量跌破派发区 | Upthrust 后做空 |

## 二、可操作的三个信号

### Spring（弹簧 / 假跌破）
吸筹区下沿被跌破，但**当天快速收回**，成交量放大后迅速萎缩。

```
条件：
1. 价格在区间内横盘 ≥ 20 根 1h
2. 跌破区间下沿，但 1–3 根内收回区间内
3. 跌破那根量能 ≥ 均量 1.5 倍，收回那根量能 ≥ 跌破那根
4. OI 在跌破期间下降（是多头被扫，不是空头进场）
→ 做多，止损在弹簧低点下方
```

### Upthrust（上冲回落）
派发区上沿被突破后迅速跌回，是对 Spring 的镜像。

### No Supply / No Demand（无供给/无需求 K 线）
- **No Supply**：小实体、缩量、收在区间下沿附近 → 卖压枯竭 → 做多
- **No Demand**：小实体、缩量、收在区间上沿附近 → 买盘枯竭 → 做空

## 三、与 TB/RF 的区别

| | TB | RF | WY |
|---|---|---|---|
| 看什么 | 突破 + 回踩 | 假突破 + 收回 | **量价背离** |
| 入场时机 | 突破后 | 假突破后 | 弹簧/无供给后 |
| 数据依赖 | 量 + 买占比 | 影线比例 | **量能 + OI + spread** |

**重叠处理**：Spring 和 RF 的假跌破很像。区别是 Spring 要求"收回速度更快 + OI 下降"，RF 要求"上影线比例"。同一笔按先满足者归类。

## 四、止损与目标

| | Spring 做多 |
|---|---|
| 止损 | 弹簧最低点下方 0.1% |
| 目标 | 区间上沿（1–1.5R）→ 突破后延伸 |
| 失效 | 价格再次跌破弹簧低点 |

## 五、已知难点

- "吸筹区"和"派发区"的判定仍有主观性 → 用 **20 根 1h 的横向区间**做硬性定义
- 量能标准需要按品种校准（小币的量能波动天然大）

## 六、启用条件

先用历史数据标注 20 个 Spring / Upthrust 案例，确认标法一致后启用。
